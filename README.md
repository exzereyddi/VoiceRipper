## 🤔 О чём тут

Была создана закрытая утилита (в 2022, автор Garey) под названием `DemRead.exe`, которая умела парсить демки CS 1.6 и вытаскивать из них голосовой чат. Исходников нет, только компил exe без всякой документации. (возможно — ибо я её не нашёл).

Разобрал что она делает, нашёл откуда растут ноги (движковый код `ReHLDS`), переписал идею с нуля на C++ — и выложил опенсурсно, чтобы больше не терялась.

Внутри — настоящий **bit-level парсер** сетевого протокола GoldSrc (не байтовая эвристика "на глазок"), который правильно проходит все `svc_*` сообщения демки, включая дельта-сжатые (`svc_clientdata`, `svc_packetentities`, `svc_event` и т.п.), чьи схемы полей узнаются только во время чтения самой демки через `svc_deltadescription`.

## ⚡️ Что умеет

| Категория | Функции |
|---|---|
| 🎙️ **Голос** | Авто-определение кодека (Speex / Silk / Opus) на лету, покадровая синхронизация |
| 👤 **Игроки** | Ник + SteamID из демки, сортировка по времени разговора |
| 📦 **Батч** | Папка / `.zip`-архив / несколько файлов разом — всё в один прогон |
| ⚙️ **Параллельность** | Демки обрабатываются одновременно по числу ядер процессора |
| 🔁 **Дедупликация** | Запоминает обработанные демки по содержимому файла, повторно не делает |
| 🎚️ **Нормализация** | Автоматическое выравнивание громкости (AGC) |
| 🔊 **Вывод** | `.wav` на каждого + общий микс `all.wav` с реальным таймингом демки |

## 🗂️ Структура проекта

```
src/
├── demo/           # чтение .dem + bit-level парсинг сетевых сообщений
│   ├── DemoFile        — контейнер .dem, фреймы
│   ├── BitReader       — побитовое чтение (как в движке)
│   └── NetMsgParser    — разбор всех svc_* + дельта-схемы
├── voice/          # извлечение и декодирование голоса
│   ├── VoiceExtractor  — сбор голосовых чанков по игрокам
│   ├── VoiceCodecs     — Speex/Silk/Opus авто-детект
│   ├── Normalize       — выравнивание громкости
│   └── WavWriter       — вывод .wav / .mp3
├── batch/          # CLI: аргументы, батч, дедуп, отчёт
└── main.cpp        # точка входа

third_party/        # Speex, Silk, Opus, miniz (всё вендорное, без системных зависимостей)
```

## 🚀 Как собрать

Нужен CMake 3.16+ и компилятор с поддержкой C++17 (проверено на MSVC / VS2022).

```
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Готовый `voiceripper.exe` — в `build/Release/`.

> [!NOTE]
> Экспорт в `.mp3` (`--mp3`) включается сам, если на машине найдётся `libmp3lame` — никакой ручной настройки не требуется, просто будет только `.wav` без него.

## 🎮 Как юзать

Перетащи `.dem`-файл, папку с демками или `.zip`-архив на `voiceripper.exe` — и всё, он сам разберётся.

```
voiceripper.exe demo.dem                 — одна демка
voiceripper.exe papka\                   — все .dem в папке (рекурсивно)
voiceripper.exe demos.zip                — распаковать и обработать архив
voiceripper.exe a.dem b.dem c.dem        — несколько сразу
voiceripper.exe demo.dem --mp3           — ещё и .mp3 рядом с .wav
```

Рядом с exe появится папка `<имя демки>_voice\` с файлами игроков и общим `all.wav`. Если голоса в демке нет — папки не будет вообще.

Полный список флагов — в `cli.md` рядом с exe (`--help` тоже работает).

## 🧩 Что можно докрутить

- 📝 **Транскрипт** — прогнать через офлайн speech-to-text и получить текст "кто что сказал"
- 📊 **CSV/JSON отчёт** — сводка по всем демкам батча в машиночитаемом виде
- 🎯 **Фильтр по игроку** — вытащить только конкретный SteamID из пачки демок
- 🗜️ **FLAC вместо WAV** — тот же lossless, но в разы меньше весит
