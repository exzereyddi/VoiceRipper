# VoiceRipper — справка

**Перетащи .dem / папку / .zip на voiceripper.exe. Без аргументов = спросит путь. С аргументами = сразу работает.**

## Команды CLI

```
voiceripper.exe demo.dem                 — вытащить голос из одной демки
voiceripper.exe papka\                   — обработать все .dem в папке (рекурсивно)
voiceripper.exe demos.zip                — распаковать и обработать все .dem из архива
voiceripper.exe a.dem b.dem c.dem         — закинуть несколько сразу (как drag&drop пачкой)
voiceripper.exe demo.dem --mp3            — ещё и .mp3 рядом с .wav
voiceripper.exe demo.dem -q               — минимум текста в консоли
voiceripper.exe demo.dem --force          — переделать, даже если уже обработана раньше
```

## Что получаешь

Рядом с .exe появляется папка `<имя демки>_voice\`:
- по одному `.wav` на каждого говорившего — `[время_первой_фразы]STEAM_ID_ник.wav`
- `all.wav` — все вместе, с реальными паузами, как было в игре (длина = длина демки)

Если в демке никто не говорил — папка не создаётся вообще.

## Флаги

| Флаг | Что делает |
|---|---|
| `-o <папка>` | Сохранять не рядом с exe, а в указанную папку |
| `--mp3` | Доп. экспорт в .mp3 (если на машине есть libmp3lame) |
| `--no-speex` / `--no-silk` / `--no-opus` | Отключить конкретный кодек (для отладки) |
| `--no-normalize` | Не выравнивать громкость |
| `--trim-silence` | Схлопывать длинные паузы тишины |
| `--force` | Обработать заново, даже если уже было (см. ниже) |
| `--no-autoclose` | Не закрывать консоль через 3 сек, ждать Enter |
| `-q`, `--quiet` | Короткий вывод (одна строка на демку) |
| `-h`, `--help` | Эта справка |

## Повторная обработка (дедупликация)

Программа запоминает, какие демки уже обрабатывала (по содержимому файла, не по имени — переименованная копия тоже узнается). Повторный запуск на той же демке — мгновенный пропуск. Список обработанного лежит в `voiceripper_done.txt` рядом с exe. Хочешь переделать — `--force`.

## Батч (несколько демок разом)

Обрабатываются параллельно (по числу ядер процессора), не одна за другой. В конце — общая сводка:

```
3 demo(s) processed: 2 with voice, 1 empty, 0 failed
```

- **with voice** — нашёл и записал голос
- **empty** — демка открылась, но голоса в ней нет
- **failed** — демка не открылась (битая / не тот формат)

Если на демке часто теряется синхронизация при разборе сети (бывает на редких протоколах), покажется `[WARN]` — голос всё равно вытащен, но часть могла потеряться.

## Как это устроено (коротко)

Разбирает сырой формат демки Half-Life/CS 1.6 (`.dem`), вытаскивает из сетевого потока голосовые пакеты (`svc_voicedata`), декодирует их кодеками Speex/Silk/Opus (разные версии игры использовали разные), сопоставляет слот игрока с его ником и SteamID, нормализует громкость и пишет WAV. Опенсурсная переработка идеи закрытой утилиты, которая делала то же самое году эдак в 2022.
